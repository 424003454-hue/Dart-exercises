Scenario: Student Grade Calculator

This Dart program calculates a student's final grade by adding bonus points to the original grade. It checks if the student passed and if the student achieved excellent performance.

Data Types Used

- String – Stores the student's name ("studentName").
- int – Stores the original grade, bonus points, and final grade ("grade", "bonus", and "finalGrade").
- double – Stores the passing grade ("passingGrade").
- bool – Stores the results of the passing and excellent performance checks ("isPassed" and "isExcellent").

Arithmetic Operators

- Addition ("+") – Adds bonus points to the original grade.
- Example: "int finalGrade = grade + bonus;"
- Calculation: "90 + 5 = 95"

Comparison Operators

- Greater than or equal to (">=") – Checks if the grade meets the passing grade.
- Example: "bool isPassed = grade >= passingGrade;"
- Greater than or equal to (">=") – Checks if the final grade is 90 or higher.
- Example: "bool isExcellent = finalGrade >= 90;"

How to Run

1. Open the project folder in a terminal.

2. Make sure Dart SDK is installed.

3. Run the following command:
   
   "dart run"

4. Check the output in the terminal.
